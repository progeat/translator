# Translator

Это интерактивное React-приложение создано в рамках хакатона, где задача стояла в том, чтобы в коммандной разработке реализовать приложение "Переводчик".

## Особенности

- Смена языка страницы

- Всплывающий тултип с переводом выделенного текста

- Виджет переводчика с выбором языков перевода

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/progeat/translator.git
```

Перейдите в директорию проекта:

```bash
cd translator
```

Установите зависимости:

```bash
npm install
```

Настройте файл окружения:

Для этого переименуйте файл .env.example в .env

И настройте файл окружения

1. Создайте аккаунт [yandex console](https://yandex.cloud/ru/docs/iam/operations/sa/create)
2. Создайте 2 api ключа:
   - API ключ для сервиса переводчика
   - API ключ для сервиса речевого воспроизведения
3. Получите ID папки из консоли
4. Заполните файл .env нужными данными полученных ключей

Запустите приложение:

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:5173

## Используемые технологии

- Feature-Sliced Design

- React Router

- Redux Toolkit

- i18n

- Yandex Translator API

- Mui Material

- Vite

## Функциональность

- Смена языка страницы

- Всплытие тултипа при выделении текста

- Перевод текста на выбранный язык в тултипе

- Виджет с переводчиком с возможностью вводить собственный текст
